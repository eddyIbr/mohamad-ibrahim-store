# Mohamad Ibrahim Store - Angular Ecommerce Project

A responsive Angular ecommerce catalogue that satisfies the Project 1 requirements:

- 15 products
- 5 product categories
- Product grid and product cards
- Product name, description, price, and stock status
- Header with store name, search field, and cart button
- Left-side category navigation
- Category filtering
- Live product search
- Responsive desktop and mobile layouts
- Angular routing with `/products/all` and category URLs
- Vercel SPA rewrite configuration

## Project URLs

Replace these placeholders after publishing through your own authenticated accounts:

- Public GitHub repository: `https://github.com/YOUR-USERNAME/mohamad-ibrahim-store`

## Run the Angular application

```bash
npm install
npm start
```

Then open `http://localhost:4200/products/all`.

## Production build

```bash
npm run build
```

The Vercel output directory is configured as:

```text
dist/mohamad-ibrahim-store/browser
```

## Vercel deployment

1. Sign in to Vercel.
2. Select **Add New > Project**.
3. Import the public GitHub repository.
4. Confirm the Angular framework preset.
5. Deploy.
6. Open `/products/all` and copy the final public URL.
